# real_estate_dashboard_project
 Real Estate - Housing Price Analysis Dashboard | Power BI Project
Excited to share my latest Power BI Dashboard project on Real Estate Housing Price Analysis! 📊🏠
In this project, I analyzed housing data to understand how different property features influence housing prices. The dashboard provides an interactive and clear view of important factors such as bedrooms, bathrooms, parking, stories, furnishing status, air conditioning, basement, guestroom, and house area.

🔍 Key Highlights:
📊 Analyzed average housing prices and important property metrics
🏠 Explored the relationship between house area and price
📈 Compared prices based on property features and facilities
🎯 Added interactive slicers for easy data exploration
📌 Designed KPI cards and multiple visualizations for better insights
🔄 Included a Clear All Slicers option for improved user experience

🛠️ Tools Used:
Microsoft Power BI
Data Analysis
Data Visualization
